# Mubarak Alao — Constellation Portfolio

An interactive personal portfolio built around a constellation-inspired navigation system.

Instead of a traditional navigation bar, the portfolio uses floating nodes around a central hub. Each node leads to a different part of my portfolio, creating a simple but interactive way to explore my work, skills, journey, and goals.

## ✦ Features

- Interactive constellation-style navigation
- Animated floating nodes
- Interactive central hub and hidden message
- Responsive design for desktop, tablet, and mobile
- Smooth section transitions
- Custom cursor on desktop
- Loading animation
- Projects and certifications showcase
- Contact and social links
